# Nostra

Nostra is a responsive fashion e-commerce website created using HTML, CSS, and JavaScript.

## Features

* Responsive design
* Navigation bar
* Product section
* Search functionality
* User-friendly interface

## Technologies Used

* HTML
* CSS
* JavaScript

## Project Structure

```text
Nostra/
├── index.html
├── Style.css
├── script.js
└── images/
```

## How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
